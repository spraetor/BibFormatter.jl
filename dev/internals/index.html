BibFormatter._buildLatexSpecialReplacements — Method

Build exact-string replacement rules for LaTeX symbol commands.

For accent commands we support three common source encodings:

  1. {\<cmd><x>}
  2. \<cmd>{<x>}
  3. \<cmd><x>

For macro commands (e.g. \ae, \ss) we support:

  1. {\<cmd>}
  2. \<cmd>{}
  3. \<cmd>

BibFormatter.BibliographyStyleUrlbst.postprocessBlocks — Method
postprocessBlocks(fmt, style, data, blocks) -> Vector{String}

Apply urlbst-specific postprocessing to bibliography blocks generated by the wrapped base style.

Processing steps:

  1. Start from a copy of the already formatted base blocks.
  2. If style.inlinelinks is enabled and the entry has web references, attach a hyperlink to the first suitable primary block.
  3. Append explicit URL-reference blocks (url, eprint, doi, pubmed) as returned by formatWebReferences, honoring style options.
  4. If inline linking is enabled but no suitable block exists, append a fallback link block using vars.linktextstring.

The function returns a new Vector{String} and does not mutate the input.

BibFormatter.BibliographyStyleAcm.formatInNames — Method
formatInNames(out, names)

Format names for nested "In ..." contexts (for example editors in incollection or inproceedings entries). Unlike formatNames, each name is rendered as "F. von Last, Jr" (formatNameFLast), and for lists longer than two names it inserts an Oxford comma before the final "and".

BibFormatter.BibliographyStyleAcm.formatNames — Method
formatNames(out, names)

Format names in ACM bibliography style for top-level author/editor lists. Each name is rendered in "von Last, Jr, F." order (formatNameLastF), with ACM separators: A, B, and C (or , et~al. for others).

Use this for primary name lists such as formatAuthors/formatEditors. For names inside an In ... phrase, use formatInNames, which uses a different per-name order and final separator behavior.
