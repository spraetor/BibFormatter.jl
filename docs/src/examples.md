# Examples

This page renders actual output generated by `BibFormatter.format(...; fmt=:html)`.
The example `Article` includes DOI-related metadata.

## Rendered Entry: `Article`

The following outputs were generated from the current code during documentation update.

```@raw html
This is a note.</p></blockquote>
```
